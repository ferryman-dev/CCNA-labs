## Small Office Network

A small office network built in Cisco Packet Tracer.

### Features

- **VLAN 10 — STAFF** (PCs 0, 1, 4, 5)
- **VLAN 20 — MANAGEMENT** (PCs 2, 3)
- **802.1Q trunking**
- **Inter-VLAN routing using Router-on-a-Stick**
- **DHCP server**
- **DHCP relay using ip helper-address**
